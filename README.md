# BAYT TECH
### Home Service Laptop Bandung

Website resmi BAYT TECH untuk layanan Home Service Laptop di Bandung dan sekitarnya.

---

# Tentang Website

BAYT TECH adalah website jasa perbaikan laptop yang menyediakan berbagai layanan seperti:

- Servis Laptop / PC
- Install Windows
- Upgrade SSD & RAM
- Cleaning Laptop
- Backup Data
- Home Service

Website ini dibuat menggunakan:

- HTML5
- CSS3
- JavaScript
- Font Awesome
- AOS Animation

Tanpa framework sehingga mudah dipelajari dan dikembangkan.
